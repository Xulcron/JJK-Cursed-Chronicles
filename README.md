# JJK-Cursed-Chronicles
Jujutsu Kaisen inspired gacha game that has character summoning, rarity tiers, character collection, and turn based combat with special and unique abilities for certain rare characters.

## Features
- Gacha system with random character summons
- Four rarity tiers: UR, SSR, SR, and R
- Single and 10 pull summons
- Compensates some money back if get duplicate characters
- Character collection
- Turn-based combat
- Different attacks and character-specific abilities
- Rewards for winning battles

## Character Rarities
| Rarity | Description |
|---|---|
| UR | Highest rarity |
| SSR | High rarity |
| SR | Medium rarity |
| R | Standard rarity |

## Gacha System
- One summon costs 300 currency
- 10 summons costs 3,000 currency
- Characters are randomly selected from their rarity categories
- Summoning a duplicate character will grant you back 100 currency
- Hint: (If you want a better chance at getting the rare characters with special abilities, go in the code and remove the hashtag for lines 14 and 15)

## Battle System
- Select a character from your collection
- A character's rarity determines your starting health for you and your opponent
- Choose an attack during each turn
- Certain characters can use special ultimates when conditions are met (look at code to see conditions)
- Defeating your opponent will earn you 1,500 currency

## Technology Used
- Python
- random module for random summons and random attack
- time module for timed pauses
- Functions, lists, loops, conditionals, and user input

## How to Run
- Download or clone this repository
- Open the project in a Python editor
- Run the Python file
